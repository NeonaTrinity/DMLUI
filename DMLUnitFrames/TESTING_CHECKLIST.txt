DMLUI Unit Frames 2.0.96 - test checklist

Core frame behavior
[ ] Player/Target/Focus/Pet/ToT/Party frames enable and disable correctly.
[ ] Left-click targets; right-click opens the normal Blizzard unit menu.
[ ] Frame scales clamp to 0.50x-2.00x; All applies uniformly.
[ ] Grouped/freeform party positions remain separate and spacing applies only in grouped mode.

Range fading
[ ] Party spell dropdown contains only known ranged helpful spells and collapses duplicate ranks.
[ ] Enemy Target spell dropdown contains only known ranged harmful spells and collapses duplicate ranks.
[ ] Dropdown rows show spell icon, spell name and detected max range.
[ ] A selected friendly spell fades out-of-range party members and also the Target frame when targeting that party member.
[ ] A selected harmful spell fades an out-of-range hostile Target frame.
[ ] Fade amount clamps to 10-90%.
[ ] Learning/unlearning/talent changes rebuild the spell lists without /reload.

Levels
[ ] Hostile Target/ToT/Focus levels use gray/green/yellow/orange/red Blizzard difficulty colors.
[ ] Units with unknown/boss level show the stock skull instead of a numeric level.

Cast bars
[ ] Player cast bar toggle works and Above/Below placement works.
[ ] Target cast bar toggle works for casts and channels, with Above/Below placement.
[ ] Target-of-Target cast bar toggle works for casts and channels, with Above/Below placement.
[ ] Cast bars track start/stop/fail/interrupt/delay/channel events and hide at completion.
[ ] Cast bars inherit the selected unit-frame scale and match frame width.

Regression
[ ] Action Bars and J3Spells behavior is unchanged.
[ ] No item-based range checks are introduced.
