DMLUI Unit Frames 2.0.92 - test checklist

BASE REGRESSION
- Open DMLUI > Unit Frames.
- Player/Target/Focus/Pet/Target of Target still enable independently.
- Left click targets.
- Right click opens the Blizzard-style unit popup menu.
- Portrait scale selector and numeric entry still clamp from 0.02 to 30.00.

PARTY ENABLE / STOCK REPLACEMENT
- Join a party with 1-4 other players.
- Enable Use DML party frames and Apply.
- Blizzard PartyMemberFrame1-4 should be hidden and DML party frames should appear for existing party units.
- Disable Use DML party frames and Apply; Blizzard party frames should return.

PARTY PETS
- With a party member pet active, enable Show party pets.
- Verify partypet1-4 appear only when those units exist.
- Disable Show party pets and Apply; DML party pets should hide.

GROUPED MODE
- Enable Move party frames as one anchor.
- Show Anchors on, Lock Frames off.
- Large DML Party Frames anchor appears above Party 1.
- Drag it; all party members and pets move together.
- Change Party spacing from 0 through larger values; party rows tighten/spread vertically.
- Set Party pet position Right then Below; pets stay attached to their owner.
- Individual + handles should not be active in grouped mode.

FREEFORM MODE
- Uncheck Move party frames as one anchor and Apply.
- Large group anchor disappears.
- Small + drag handles appear beside each party member and enabled party-pet portrait.
- Move Party 1, Party 2, and individual pets independently.
- Party spacing and Party pet position controls should be disabled and have no layout effect.
- Switch back to grouped mode; previous grouped layout should return.
- Switch back to freeform; previous individual positions should return.

PARTY PORTRAIT SCALE
- Select Party Members and change scale; all party member portraits change together.
- Select Party Pets and change scale; all party pet portraits change together.
- Individual Party 1-4 entries use the Party Members shared scale.
- Individual Party Pet entries use the Party Pets shared scale.

RESET FRAME
- Move/scale Player, select Player, click Reset Frame; Player returns to default position and portrait scale.
- Move Party 2 in freeform, select Party 2, click Reset Frame; its saved freeform position returns to default.
- Select Party Group, click Reset Frame; grouped anchor, spacing, and grouped pet placement return to defaults.

RESET ALL FRAMES
- Customize several normal frames, grouped/freeform party positions, spacing, and portrait scales.
- Click Reset All Frames.
- All positions/scales should return to defaults.
- Enabled replacement checkboxes must NOT change.

COMBAT SAFETY
- Enter combat and try Apply / Reset Frame / Reset All Frames.
- Protected layout changes should be blocked with a chat message rather than tainting or moving secure frames.
