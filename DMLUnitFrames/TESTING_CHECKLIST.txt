[ ] Duplicate ranks collapse to one Healing Wave entry.

[ ] Aggro border disappears when aggro is lost.

[ ] Increasing intensity visibly increases border width/opacity.

2.0.100 display/color checks:
- Show class affects player class text only.
- Show creature type affects non-player creature type text only.
- Name color swatch changes fallback name color.
- Use class color as name overrides the custom name color for player units only.
- Use class color for class text colors player class text independently of name coloring.

2.0.102 portrait type checks
- Portrait type dropdown offers 2D Portrait, 3D Portrait, and Class Icon.
- 2D Portrait matches the previous DML portrait behavior.
- 3D Portrait shows a live 3D model for player, target, focus, pet, ToT, party, and party-pet units.
- Class Icon shows the correct class icon for the player and friendly player units (including friendly player targets/party members).
- With Class Icon selected, enemies (including enemy players), NPCs, and pets fall back to their normal 2D portrait.
- Rare/elite dragon ornament and combat icon remain above both 2D and 3D portraits.
- Turning Show portrait off hides both texture and 3D model; turning it back on restores the selected mode.


2.0.103 3D portrait camera/regression checks
- 3D Player portrait is cropped to roughly shoulders/top of head rather than showing the full body.
- 3D hostile target portrait uses the same close portrait framing.
- 3D pet, focus, ToT, party, and party-pet portraits remain correctly framed.
- Health/resource/name updates do not visibly reset or zoom the 3D model.
- Changing target rebinds the 3D model immediately.
- Shapeshifting/transforming refreshes the 3D portrait through UNIT_MODEL_CHANGED.
- Switching 2D -> 3D after a model change displays the current model.
- Rare/elite ornament and combat icon remain above the 3D portrait.

2.0.104 3D portrait camera validation:
- 3D portrait uses the native Wrath camera 0 facial view: no full-body character should be visible in the portrait box.
- Player, target, focus, pet, target-of-target, party, and party-pet 3D portraits show the unit face/head portrait when visible.
- /reload, Alt-Z/UI hide-show, target changes, shapeshifts, and transformations retain/reapply the facial camera.


2.0.105 classification dragon validation:
- Rare, rare-elite, elite, and world-boss dragon ornaments are horizontally mirrored.
- The dragon wing/ornament extends to the LEFT of the portrait instead of the right.
- Dragon art still sits correctly around both 2D and 3D portraits without covering the unit bars/text.
- Combat icon layering remains above the portrait.


2.0.106 alignment-name validation:
- With Use alignment color for name OFF, non-player names use the configured Name color.
- With it ON: hostile/hated NPC names are red, unfriendly NPC names orange, neutral NPC names yellow, and friendly-or-better NPC names green.
- Player names are not reaction-colored; Use class color as name still independently controls player-name class coloring.
- Changing target/faction/reaction refreshes the visible name color without /reload.

2.0.106 cast-bar independence validation:
- DML Cast Bar OFF + Hide Blizzard cast bar OFF + attached Player cast bar ON: Blizzard bar and attached Player bar both display.
- DML Cast Bar OFF + Hide Blizzard cast bar ON + attached Player cast bar ON: only the attached Player bar displays.
- DML Cast Bar ON + attached Player cast bar ON: DML standalone bar and attached Player bar both display; Blizzard bar stays hidden.
- DML Cast Bar ON + attached Player cast bar OFF: only DML standalone bar displays; Blizzard bar stays hidden.
- Turning DML Cast Bar back OFF restores Blizzard's bar unless Unit Frames Hide Blizzard cast bar remains checked.


2.0.114 dragon/classic-banner validation:
- Rare/elite/world-boss dragon is centered better: slightly farther left, a tiny amount lower, and slightly larger than 2.0.113.
- Dragon stays correctly aligned when the complete unit frame is scaled from 0.50x through 2.00x.
- Use classic name banner OFF leaves the normal DML name-row background unchanged.
- With it ON, hostile target/focus/ToT units get a red reaction banner, neutral units yellow, unfriendly units orange, and friendly units green.
- Hostile PvP player targets receive the hostile reaction banner too.
- Name text color remains independently controlled by class/alignment/custom name-color settings.
- Installing/removing DMLBuffs does not break Unit Frames.
