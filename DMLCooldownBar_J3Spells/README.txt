DMLUI - Action Bars - J3Spells Integration 2.0.90

Optional companion addon for DMLCooldownBar. Install only for a WoW 3.3.5a
server running the J3Spells/ALE DMLCD protocol.

The main DMLCooldownBar addon works without this folder. When this addon is
available, enable it inside DML configuration with:

  J3Spells Lua (use with j3spells module only)

Native spell/item cooldowns remain active. J3 timers supplement/override only
spells driven by the server integration.
