DMLCooldownBar 2.0.77
- Unified named profiles and automatic character layouts into one account-wide Saved Profile list.
- Copy Profile now reads the same list as Saved Profile; Delete removes entries from both views immediately.
- Migrates legacy Character-Realm snapshots once, preserving existing named profiles, then retires characterLayouts.

DML Cooldown Bar 2.0.76
=======================

- Fixed idle memory growth and random garbage-collection spikes by reusing the
  0.1-second update loop's cooldown, resource, and range scratch tables.
- Replaced the unbounded Bagnon item-link negative cache with a 512-entry cap,
  preventing permanent growth while retaining fast repeated bag refreshes.
- Removed the temporary return-value table allocated for every Bagnon item-slot
  refresh while still preserving the upstream function's exact return values.
- Reduced additional allocation churn on bag, resource, companion, and full-bar
  refresh paths by using reusable callbacks and scratch caches.
- Added drag-and-drop macro support for normal DML bars. Macro names, icons, and
  bodies are saved with profiles and character layouts, and buttons execute them
  through secure macro clicks and keybinds.
- Added macro support to DML-to-DML moving/swapping and Bar 1 stance pages.
- Preserved custom spells, custom items, mounts, companion pets, the combat pet
  bar, cooldown protocols, and current profile data.

DML Cooldown Bar 2.0.75
=======================

- Made Bagnon compatibility safe to leave enabled by preserving every return
  value from the installed Bagnon slot API instead of truncating the result.
- Added non-stacking, reversible Bagnon wrappers; disabling compatibility now
  removes DML's direct hooks when safe and otherwise becomes a transparent
  pass-through without disrupting other addons.
- Changed assigned-item resolution to one GetItemInfo call with a session cache
  and a five-second retry delay for unresolved item data.
- BAG_UPDATE now refreshes only DML item assignments, while
  GET_ITEM_INFO_RECEIVED refreshes only buttons for the reported item ID.
- Preserved custom item icons, secure item clicks, cooldowns, profiles, mounts,
  companion pets, combat-pet bar behavior, and all custom metadata files.
